# Мотиваційний Telegram-бот

Бот працює через GitHub Actions, тому комп'ютер не потрібно залишати ввімкненим.
Python використовує лише стандартну бібліотеку, встановлення пакетів не потрібне.

## Повідомлення й розклад

Поки що встановлено **кожні 2 години за київським часом**:
09:20, 11:20, 13:20, 15:20, 17:20, 19:20, 21:20, 23:20.

Кожна серія містить три окремі повідомлення:

1. На початку: «🚫🍾 Я не вживаю алкоголь».
2. Через 5 хвилин: «🚬🚫 Я не курю».
3. Ще через 5 хвилин: «🍗🚫 Я дотримуюсь дефіциту калорій».

Отже, остання серія запланована на 23:20, 23:25 і 23:30.
Часова зона `Europe/Kyiv` автоматично враховує сезонну зміну часу.

GitHub Actions може затримувати або пропускати заплановані запуски;
це не сервіс гарантованої доставки точно до хвилини.
Пауза 5 хвилин рахується після успішної відповіді Telegram на попереднє повідомлення.
Запуски, що починають перевірку поза 09:00–23:21, пропускаються, щоб не писати вночі.
Ручний запуск також дотримується цього обмеження.

## Як увімкнути

1. Відкрийте [BotFather](https://t.me/BotFather) у Telegram, надішліть `/newbot`
   та створіть бота. Збережіть отриманий токен.
2. Відкрийте створеного бота й натисніть **Start** або надішліть `/start`.
3. У цій папці виконайте `python get_chat_id.py`. Вставте токен у приховане
   поле вводу. Скрипт покаже ID вашого чату — збережіть число.
4. Створіть репозиторій GitHub і завантажте файли цього проєкту, зокрема
   приховану папку `.github` з файлом `.github/workflows/reminders.yml`.
   Workflow має бути в основній гілці репозиторію.
5. Відкрийте **Settings → Secrets and variables → Actions → New repository secret**.
   Додайте два секрети:
   - `TELEGRAM_BOT_TOKEN` — токен від BotFather;
   - `TELEGRAM_CHAT_ID` — числовий ID вашого приватного чату.
6. Відкрийте **Actions → Telegram reminders → Run workflow** у дозволений час.
   Перше повідомлення прийде після початку виконання, решта — через 5 і 10 хвилин.

Токен не записуйте у файли репозиторію. Скрипт отримання ID не зберігає його.
Якщо бот уже використовує webhook, `getUpdates` не працюватиме: використовуйте
окремого бота для цих нагадувань.

## Змінити частоту або тексти

У `.github/workflows/reminders.yml` змініть cron:

- Щогодини: `20 9-23 * * *`.
- Кожні 2 години: `20 9-23/2 * * *`.
- Кожні 3 години: `20 9-23/3 * * *` (останній запуск о 21:20).

Тексти містяться в `MESSAGES` у `bot.py`.
Якщо потрібно завершувати всі повідомлення строго до 23:00, приберіть
запуск о 23:20, наприклад установіть `20 9-21/2 * * *`.

## Перевірка без надсилання

```powershell
python bot.py --dry-run
python -m unittest -v
```

Кожен запуск займає приблизно 11 хвилин GitHub Actions. Для приватного
репозиторію враховуйте ліміт хвилин вашого тарифу. У публічному репозиторії
GitHub може вимкнути розклад після 60 днів без активності в репозиторії.
Вимкнути нагадування вручну: **Actions → Telegram reminders → … → Disable workflow**.

Документація: [розклади GitHub Actions](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule),
[часові зони](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax#onschedule),
[Telegram Bot API](https://core.telegram.org/bots/api#sendmessage).
